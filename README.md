# PassingBy

An AI-powered tour guide for the road. As you drive, PassingBy tells you about nearby attractions worth exploring and the history of the places you're passing through.

## Status

Early development. Nothing to install yet.

## Planned features

- Discover nearby attractions based on your current location
- Short spoken stories about the history of the area around you
- Hands-free, driver-friendly experience

## Privacy

PassingBy uses your location only to find what's around you. It is designed to avoid storing location history.
